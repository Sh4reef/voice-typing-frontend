Hardware Security

Our Security & Permissions Promise

Operating system overlay engines require specific native access privileges. Here is a clear breakdown of why VoiceTyping invokes these APIs:

  • 🔐
    Accessibility Frameworks:

    Required to insert text directly into active windows. We trigger macOS Accessibility/CGEventPost, Windows Win32_UI_Input, and Linux X11/xtst APIs to emulate standard keyboard typing actions safely.

  • 🎙️
    Microphone Hardware Access:

    We initialize hardware recording buffers strictly during the "Recording" state. The audio stream is compiled directly into memory array blocks, passing immediately to the transcriber without saving any audio files to disk.

  • 🚫
    Zero Telemetry (Free Tier):

    The local client has no networking capabilities compiled for local engine actions. Absolutely no usage statistics, voice signatures, or keystrokes are transmitted.
